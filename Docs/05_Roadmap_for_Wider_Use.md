# Roadmap for Wider Academic Use

JournalFit Studio is currently a local-first prototype. It can be strengthened into a broader academic journal-discovery platform through technical, governance, and data-quality improvements.

## 1. Metadata improvement

- Create a verified journal metadata schema.
- Add source URL and verification date for each record.
- Separate official URLs from search links.
- Maintain aims and scope summaries from official journal pages.
- Add article type, method preference, APC, review model, and indexing fields where verified.

## 2. Responsible-use controls

- Add a mandatory verification step before report export.
- Add visible reminders that journal-fit scores are not acceptance probabilities.
- Maintain a responsible-use policy inside the app.
- Provide role-specific guidance for researchers, mentors, and research offices.
- Create a public changelog for interface language changes.

## 3. Scalability

- Move from a single-file local prototype to a modular application architecture.
- Add a metadata administration panel.
- Add database-backed storage for institutional deployments.
- Add authentication, role-based access, and audit logs.
- Add Docker and reverse-proxy deployment templates.

## 4. Privacy and security

- Offer local-only mode for confidential manuscripts.
- Define hosted-demo privacy limitations clearly.
- Add configurable file-retention policy.
- Avoid retaining uploaded manuscript content unless explicitly enabled.
- Conduct institutional security review before public large-scale deployment.

## 5. Better fit evidence

- Improve field detection and journal-scope matching.
- Add transparent scoring calibration reports.
- Allow users to compare recommendations across metadata sources.
- Add manual reviewer notes and final decision tracking.
- Add exportable evidence sheets for supervisor or research-office review.

## 6. Accessibility and usability

- Improve small-screen layouts.
- Add keyboard-friendly navigation.
- Add high-contrast mode.
- Improve explanatory text for early-career researchers.
- Add guided onboarding and sample workflows.

## 7. Wider community use

The long-term goal is to develop JournalFit Studio into a responsible journal-discovery tool for a wider academic community. Such a version should be governed carefully, with clear attribution, transparent metadata practices, and strong separation between journal suitability and ranking interpretation.
